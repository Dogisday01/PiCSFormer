PiCSFormer: распознавание аккордов в аудио

Магистерская диссертация «Development of Machine Learning Models for Musical Chord Recognition in Digital Audio». Нұрым Абзал, Astana IT University. Состояние на 24.11.2026.

Это чистая копия проекта: только код итоговой модели PiCSFormer (название — от выхода «набор высот», pitch-class set, и Transformer; пакет chordrec), веса 15 обученных моделей и сохранённые числа. Ноутбук показывает, где в коде каждый механизм и каждое правило распознавания, сколько каждый дал, итоговые результаты и распознаёт аккорды в аудиозаписи прямо здесь. Код проверен против исследовательского кода, на котором получены числа диссертации: те же веса дают те же ответы (tests/check_against_research.py, раздел 8).

Как читать числа

  • Мера — взвешенная полнота символов аккордов (WCSR, mir_eval): доля времени записи с верным ответом на данном уровне, %.
  • Уровни: root — основной тон; majmin — мажор или минор (C, Cm); triads — трезвучие целиком (C, Cm, Cdim, Caug, Csus4); sevenths — мажор, минор и септаккорды C7, Cmaj7, Cm7; tetrads — все четырёхзвучия (Cdim7, Cm7b5 и др.); MIREX — совпадают хотя бы три звука аккорда.
  • «15 моделей» — 5 фолдов кросс-валидации по группам GuitarSet × 3 seeds. Разница рецептов — среднее 15 пар; «фолдов > 0» — в скольких фолдах из 5 она положительна.
  • Наборы: GuitarSet DEV — 24 записи гитары; BPSD-dev без Op. 53 — 44 записи фортепиано (сонаты Бетховена); JazzSAMBA-val — 12 записей джазовых ансамблей; RWC-P — 100 записей поп-музыки.

LEVELS = ["root", "majmin", "triads", "sevenths", "tetrads", "mirex"]
SEEDS, FOLDS = (42, 43, 44), range(5)


def load(path):
    return json.loads((ROOT / path).read_text(encoding="utf-8"))


def f2(v, sign=False, nd=2):
    s = f"{v:+.{nd}f}" if sign else f"{v:.{nd}f}"
    return s.replace(".", ",").replace("-", "−")


def cube(get):
    """[5 фолдов, 3 seeds, 6 уровней]"""
    return np.array([[[get(k, s)[q] for q in LEVELS] for s in SEEDS] for k in FOLDS])


def paired(a, b):
    """b − a: среднее 15 пар и число фолдов из 5 с плюсом."""
    d = (b - a).mean(1)
    return d.mean(0), (d > 0).sum(0)


def table(head, rows, note=None):

2. Как устроено распознавание

  1. Признаки. CQT: 22 050 Гц, шаг 512 (23 мс), 36 бинов на октаву, 288 бинов от F#0, log(1 + 100·|X|); сеть читает 252 бина, запас ±6 полутонов нужен для транспозиций.
  2. Сеть. Свёрточная часть, затем 4 блока «Transformer с вращательными позициями (RoPE) + свёрточный модуль», ширина 192.
  3. Пять выходов по кадрам: мажор/минор (25), «набор высот» (12 сигмоид: звучит ли класс высоты как звук аккорда), бас (13), корень (13), ноты (88 клавиш; только при обучении).
  4. Декодер. Витерби по 180 шаблонам (12 корней × 15 качеств) и «нет аккорда»; обращение — если бас звук аккорда, но не корень.
  5. Пять правил распознавания поверх модели (раздел 5).

3. Механизмы обучения: где в коде и что дали

Сначала — основа рецепта (ранние шаги; числа из отчётов того времени, тогда распознавание шло записью целиком). Затем — шаги итогового рецепта, пересчитанные здесь из сохранённых файлов: 15 моделей шага против 15 моделей предыдущего, BPSD-dev и JazzSAMBA-val окнами 10 с, без правил распознавания.

Каждый шаг принимался по правилу, записанному до запуска: выигрыш — BPSD sevenths или majmin ≥ +1,0 (4 из 5 фолдов), устойчивая прибавка септим BPSD ≥ +0,3 (4/5) или гитара ≥ +0,3; без вреда — majmin и sevenths нигде не падают больше чем на 0,5. Решения — только по валидации; тестовые наборы для решений не используются.

4. Обучение

Одна модель — python -m chordrec.train --fold 0 --seed 42 --out runs/final; все 15 — python -m chordrec.cv --out runs/final. Рецепт: 60 эпох × 100 шагов, батч 16 отрезков по 10 с, AdamW (lr 0,001, weight decay 0,01), OneCycle, веса последней эпохи. Доли в батче: GuitarSet 0,45 · синтетика AAM 0,10 · MusicNet 0,15 · рояль 0,10 · JazzSAMBA 0,15 · ноты MAESTRO 0,05 (только голова нот). Обучение одной модели — около 35 минут на RTX 4060 Laptop плюс модели-учителя; данные (десятки гигабайт) читаются из исследовательского проекта, часть наборов по лицензии распространять нельзя.
